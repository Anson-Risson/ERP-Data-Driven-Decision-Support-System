# Local datasets (not committed)

The project expects these files in this folder when running locally:

- `student_academic_data_anonymized.csv`
- `student_survey_data_anonymized.csv`

They are deliberately excluded from this public repository because they contain sensitive student-related attributes. Obtain the files through an authorized private channel and keep them local.

The repository `.gitignore` excludes CSV and spreadsheet files in this folder. Do not remove these ignore rules or upload private student data to a public repository.
